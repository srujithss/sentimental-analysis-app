1. Introduction

The Sentiment Analysis application is a full-stack web application that determines whether text expresses a positive, negative, or neutral sentiment. It is designed specifically for Dravidian languages — Tamil, Malayalam, Kannada, and Telugu — and supports both native script and romanized (Latin-letter) input.

The system uses a pre-trained XLM-RoBERTa transformer model running entirely inside the JVM via ONNX Runtime, requiring no external Python service or GPU at runtime. Romanized text is automatically transliterated to native script using the ICU4J library before inference, dramatically improving accuracy for Latin-script input.

Inference Pipeline

The end-to-end prediction pipeline works as follows:

StepComponentAction
1PreprocessingServiceCleans and normalizes input text
2LanguageDetectionServiceDetects the language and script type (native vs. Latin)
3TransliterationServiceIf Latin script detected, transliterates to native script via ICU4J
4SentimentTranslatorTokenizes text with XLM-RoBERTa tokenizer
5DjlSentimentServiceRuns ONNX model inference, returns softmax probabilities
6PredictionServiceOrchestrates the pipeline, saves result to database

7. Features

🌐 Cross-lingual Sentiment

Analyzes text in Tamil, Malayalam, Kannada, and Telugu using XLM-RoBERTa.

🔄 Auto-transliteration

Romanized Latin text is automatically converted to native script via ICU4J before analysis.

📈 Confidence Scoring

Shows per-class probabilities and flags low-confidence (<60%) predictions.

📚 Analysis History

All predictions saved with filtering by language, pagination, and timestamps.

👥 User Management

Registration, login, role-based access (USER and ADMIN roles).

🛠 Admin Dashboard

Overview of users, model health status, and recent registrations.

🔎 Language Detection

Automatic detection of input language and script type (native vs. Latin).

⚡ In-JVM Inference

ONNX model runs inside the JVM — no Python, no GPU, no external service.

13. Building & Running

Prerequisites

RequirementNotes
Java 21+JDK required for building; JRE sufficient for running the JAR
ONNX model filesPlace in ./models/xlmr-sentiment/ (run python/export_model.py to generate)

Commands

# Build the project
./mvnw clean package -DskipTests

# Run with H2 (default)
java -jar target/sentiment-analysis-0.0.1-SNAPSHOT.jar

# Run with MySQL
java -jar target/sentiment-analysis-0.0.1-SNAPSHOT.jar \
  --spring.profiles.active=mysql

# Run in development mode
./mvnw spring-boot:run

First Launch

On first startup, the application will:

  1. Create the database schema automatically (H2 file or MySQL tables)
  2. Create the default admin account (admin / Admin@12345)
  3. Load and verify the ONNX sentiment model
  4. Start listening on http://localhost:8080
ⓘ
The H2 console is available at http://localhost:8080/h2-console for inspecting the database during development. Connect with JDBC URL jdbc:h2:file:./data/sentimentdb, username sa, no password.
