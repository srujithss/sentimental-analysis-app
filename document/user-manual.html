1. Application Overview

The Sentiment Analysis application determines whether a piece of text expresses a Positive, Negative, or Neutral sentiment. It is powered by the XLM-RoBERTa multilingual transformer model, trained specifically for Dravidian languages, and works with text written in native script or in romanized (English-letter) form.

Multi-language Support

Tamil, Malayalam, Kannada, and Telugu in both native script and romanized Latin text.

Auto Transliteration

Romanized text is automatically converted to native script via ICU4J for higher accuracy.

Confidence Score

Every result shows a confidence percentage and per-class probability breakdown.

Analysis History

All your analyses are saved and can be browsed, filtered by language, and paginated.

2. Model Information

The application uses a pre-trained multilingual transformer model, exported to ONNX format for fast inference inside the JVM.

Sentiment Model Details

Model Namecardiffnlp/twitter-xlm-roberta-base-sentiment
ArchitectureXLMRobertaForSequenceClassification
Base ModelXLM-RoBERTa Base (multilingual, 100+ languages)
Hidden Layers12 transformer layers, 768 hidden units
Output LabelsNegative   Neutral   Positive
Inference EngineDJL (Deep Java Library) 0.36.0 + ONNX Runtime
TransliterationICU4J 75.1 (Latin → Tamil / Telugu / Kannada / Malayalam)
Max Input Length256 tokens
Low Confidence Threshold60% (results below this are flagged)
Model Path./models/xlmr-sentiment
ⓘ
The model is originally from Hugging Face (cardiffnlp/twitter-xlm-roberta-base-sentiment), fine-tuned on multilingual Twitter data. It is exported to ONNX format via the python/export_model.py script and runs entirely inside the JVM — no Python or GPU is needed at runtime.

4. Registration

Registration page — /register
  1. Open the Registration page Navigate to http://localhost:8080/register or click "Register" on the login page.
  2. Fill in your details
    Username — must be unique, max 30 characters.
    Email — must be a valid, unique email address.
    Password — minimum 8 characters.
    Confirm password — must match the password.
  3. Click "Register" On success, you are redirected to the login page with a confirmation message.
⚠
If you see a validation error (red text below a field), correct the highlighted field and try again. Common issues: username already taken, email already registered, or passwords don't match.

5. Login

Login page — /login
  1. Open the Login page Navigate to http://localhost:8080/login. Any unauthenticated URL automatically redirects here.
  2. Enter your credentials Type the username and password you registered with.
  3. Click "Sign in" On success, you are redirected to your User Dashboard.

7. Analyzing Sentiment

Analyze page — /user/analyze
  1. Navigate to the Analyze page Click Analyze in the nav bar, or click the "Analyze text" tile on the Dashboard.
  2. Enter your text Type or paste text into the text area (up to 1,000 characters). The character counter updates in real time.
  3. Select a language (if needed)
    • Native script (e.g., മലയാളം): leave the dropdown on "Auto-detect language".
    • Romanized text (e.g., "Ee cinema valare nallathanu"): select the correct language (Tamil, Malayalam, Kannada, or Telugu) from the dropdown. This enables automatic transliteration.
  4. Click "Analyze" (or press Ctrl+Enter) The button changes to "Analyzing..." while processing.
  5. View the result The result panel appears below with the sentiment label, confidence score, probability bars, detected language, and latency.

8. Transliteration (Romanized Text)

When you type Dravidian text using English letters (romanized / Latin script), the model's accuracy drops significantly (from ~100% to ~20%). The application solves this by automatically transliterating your romanized text into native script before analysis using the ICU4J library.

Romanized text "Ee cinema valare nallathanu" transliterated to Malayalam script — Positive sentiment

How it works

  1. You type romanized text Example: Ee cinema valare nallathanu
  2. You select the language Choose "Malayalam" from the language dropdown (required for romanized text).
  3. The system detects Latin script It recognizes the input is in English letters, not native script.
  4. Automatic transliteration The text is converted to native Malayalam script (shown in the blue box above the result).
  5. Analysis runs on native script The XLM-RoBERTa model processes the transliterated text, producing much higher accuracy.
ⓘ
The transliterated text is displayed in a blue box above the result so you can verify the conversion. If you're already typing in native script, no transliteration occurs.
⚠
Important: You must select the correct language from the dropdown when entering romanized text. Without it, the system cannot determine which script to transliterate into, and accuracy will be low (~20%).

9. Understanding Results

After analysis, the result panel displays several pieces of information:

ElementDescription
Sentiment Label The predicted sentiment: Positive, Negative, or Neutral
Confidence Score How confident the model is in its prediction (0%–100%). Higher is more reliable.
Probability Bars Visual breakdown showing the probability for each of the three sentiment classes. The longest bar corresponds to the predicted label.
Language & Script The detected (or selected) language and script type, e.g., "Malayalam (Malayalam script)" or "Malayalam (Latin script)".
Transliterated Text Shown only for romanized input — the native-script version the model actually analyzed (blue box).
Latency Time taken for the model inference in milliseconds.
Code-mixed (warning) Appears when the text contains multiple scripts (e.g., Malayalam mixed with English).
Low confidence (warning) Appears when the confidence is below the threshold (default: 60%). Treat the result with caution.

14. Troubleshooting

IssueSolution
"Please contact the administrator" on the Analyze page The sentiment model is not loaded. Contact your admin to check the model files at the configured path (./models/xlmr-sentiment).
"Invalid username or password" at login Double-check your username and password. Ensure your account hasn't been disabled by an admin.
Low confidence / wrong result on romanized text Make sure you selected the correct language from the dropdown. Without it, transliteration won't activate and accuracy will be low (~20%).
"Unknown language" error You provided an unsupported language code. The system supports only Tamil (ta), Malayalam (ml), Kannada (kn), and Telugu (te).
"Please enter some text" error The text area is empty or contains only whitespace. Enter actual text before clicking Analyze.
Cannot access /admin/dashboard Only ADMIN-role accounts can access admin pages. Regular user accounts will see a 403 Forbidden error.
Page not loading / connection refused Ensure the application is running and accessible at the correct URL (default: http://localhost:8080).
